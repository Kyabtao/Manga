THREADBORN — Chapter 06 — Page 001

Chapter title: The Mother's File / माँ की फ़ाइल Arc: II — The Mendery Sector: Agnikhand — The Mendery archive, ash-slums Page type: Chapter opening — 7 panels, hook at bottom

Beats carried from Chapter 005: Ira entered the Mendery through the back door, found her mother's file (SUTAR, M. — Braid-carrier, projection type, Mendery bound), read two crimson lines: "Sewn shut" and "The braid will open. The thread will pull. The girl will come." The principal predicted her. Kessa's key is in her hand. The braided mark is open on her palm.

PANEL 1 — Wide, the archive (~14%)

Camera: The Mendery archive: tall shelves of files stretching into darkness. Dust and ash on every surface. Ira stands in the centre of the room, her mother's file open in her hands, the braided mark on her palm casting faint light on the pages. The key is in her belt.

Image: The archive is vast and silent and old. Hundreds of files, each a debt-carrier's record. Ira is the only person in the room. The mark's faint glow is the only light besides the Spindle's filtered beam from a high window.

CAPTION (Ira's voice, small): The archive held hundreds of files. My mother's was one of many. But the crimson line was only in hers.

PANEL 2 — Macro, the file (~13%)

Camera: The file in Ira's hands: grey ink columns — Name, Kind, Thread, Debt, Binding date, Release date. Her mother's name: Sutar, M. — the M stands for a name Ira has never heard spoken aloud. The Kind column says Manavkin. The Thread column says braided, projection type. The Debt column says zero.

Image: The file is old, the ink faded but legible. The crimson lines at the foot glow faintly. The same handwriting as every other crimson mark the principal has left.

CAPTION (none spoken): Name: Sutar, M. Kind: Manavkin. Thread: braided, projection type. Debt: zero.

CAPTION (smaller): Zero debt. Like her daughter. Like the thread that was never borrowed.

PANEL 3 — Close, the binding date (~14%)

Camera: The binding date: twenty years ago — five years before Ira was born. The release date column is empty. Her mother was never released.

Image: The empty release-date column is the heaviest object on the page.

CAPTION (Ira's voice, smallest): Twenty years. No release. She was never freed.

PANEL 4 — Medium, the shelves (~13%)

Camera: Ira looks up from the file at the shelves. Every file is a debt-carrier. Every carrier was bound. The Mendery is not a workhouse — it is a prison of debt. And her mother was here for five years before Ira was born.

Image: The shelves are endless. Each file a life. The archive is the Mendery's true work: not binding debt-carriers, but recording them.

CAPTION (none spoken): The Mendery binds debt-carriers. The archive records them. Her mother was one of hundreds.

PANEL 5 — Medium, the braid (~14%)

Camera: Ira's palm: the braided mark glows as she holds the file. The blank strand — the sewer's thread — reaches toward the file the way it reached toward the chain and the key. The thread recognizes its own history.

Image: The thread and the file in the same frame: the braid's blank strand touches the page where her mother's name is written.

SFX: —

CAPTION: The thread recognizes the file. The way it recognized the chain. The way it recognized the key. The braid remembers.

PANEL 6 — Wide, the archive's depth (~13%)

Camera: Ira walks deeper into the archive, file in hand, mark glowing. The shelves narrow. The files are older. At the archive's back wall, a single shelf holds files that are different — not grey Council ink, but older script. Kshudra knot-script.

Image: The back wall's files are Kshudra-made, older than the Council's records. The archive has layers: Council files in front, Kshudra files at the back.

CAPTION (none spoken): The archive has layers. Council files in front. Kshudra files at the back. The oldest records predate the Council itself.

PANEL 7 — Macro, the back wall — HOOK (~19%)

Camera: Ira's hand on the back wall's shelf: the oldest file is labelled in knot-script she cannot read. But the braided mark reads it — the blank strand touches the file and the knot-script translates: one word, visible in the thread's light.

Image: The knot-script file, illuminated by the mark's thread-light. The translated word is visible — a name, a place, a concept — that changes everything Ira knows about the Mendery.

CAPTION (none spoken): The mark translates what the girl cannot read. The oldest file in the archive opens for the thread that was braided into a girl's palm twenty years ago.

CAPTION (smaller): The Mendery's oldest record is not a debt-carrier's file. It is a thread-school's charter. And the charter's first name is the same as the name in her mother's file.

Writing & art notes

  • The archive is the Mendery's true work: not binding, but recording. Every file is a life. The visual should feel like a library, not a prison.
  • The mother's file reveals: Manavkin, braided, projection type, zero debt, bound twenty years ago, never released. The empty release-date column is the page's emotional weight.
  • The back wall's Kshudra files are the chapter's mystery: the archive has layers older than the Council. The braided mark translates knot-script.
  • The thread-school charter is the chapter's hook: the Mendery's oldest record is not a debt-carrier file but a charter for the hand-school that sewed Ira's palm. The name in the charter matches the name in her mother's file.
  • Chain budget: ONE for Chapter 006. Not to be spent early.
  • The Loom never speaks. Ash falls in the filtered light.
