THE SIXTY-FIRST KNOT (Panel 7, an object with a card line)

Not a character. Tracked from day one per 04-card-game-notes.md.

The Extra Minute / — / the silent second / n/a / owes one minute /
a knot no hand in the room owns / "knots are how you count what owes you"
