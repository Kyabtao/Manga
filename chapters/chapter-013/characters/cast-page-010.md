```
Ira Sutar / Manavkin / Agnikhand / ash-grey braided, blank core / zero, and climbing /
Mend: cancel target debt instead of paying it / "Nobody owns the table."
```
> **Page 010 note:** attends her own counter's reading in silence — a basin voice reads the
> machine's paper — and says one line of record: the terms accepted, nothing withdrawn, nothing
> regretted. Receives the first weekly delivery with both hands. The chapter's last entry is a list

> still off the record — and a counter where paper goes to be read, and nobody owns the table.

> **Page 010 note:** the arc lands: queue (P001), fetchers (P004), readers (P010) — the institution

## THE COUNT-HOUSE HAND (one-off — routine, which is the true victory)
No full sheet; Ch. 013. Not the runner: a lesser clerk — nerveless, efficient, mildly bored —
passing the first weekly delivery through the window-frame. The machine intends this as ROUTINE.

```
The Count-House Hand / Manav / Agnikhand / dust and lunch-warm wax / counts for wages /
Deliver: the machine's weeks, to the keeper's grammar /
"Sign here. Both copies. Every week."
```
> **Page 010 note:** the revolution arrives looking like clerking, because it IS clerking. A bored
> stranger on a schedule is the strongest grammar there is — the terms are not a truce anymore;
> they are a route.
